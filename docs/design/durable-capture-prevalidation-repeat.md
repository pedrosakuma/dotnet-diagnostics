1. Correct bounded persistence of the monitor's first causal error and
   preserve the original entry failure separately from subsequent cleanup or
   finalization failures, including their stages. Carry the corrected meaning through writers,
   readers, inspection and reports.
2. Add component coverage for causal-error persistence, primary/secondary
   failure precedence, exact encoding bounds and the fixture/observer
   lifecycle. Component work must not substitute a smaller workload for a
   real probe or secretly rehearse the actual O1/live/F3 matrix.
3. Independently review the code, encoding and layout derivations, negative
   admission behavior and component results. Unknown observation failures
   remain failures; no generic ignore rule, slower polling, shorter workload,
   extra resource allowance or unobserved fixture preparation is permitted.
   The cleanup-confirmation I/O failure encountered in component work must
   receive an explicit disposition with exact-identity-safe behavior and
   deterministic regression coverage, not be dismissed because later runs
   passed. Its historical errno and intermediate build are unknown; new proof
   must not be presented as a reconstruction of that missing evidence.
4. Commit and rebuild the accepted implementation in an isolated checkout.
   Resolve new binary identities, fixed encoding, field-map hashes, genuine
   component evidence, attribution, host facts and environment fingerprint.
   Preserve the prerequisite's unestablished real-worker-feasibility value.
5. Record scoped implementation acceptance and a new immutable manifest-bound
   authorization referring to this prospective scope and the maintainer's
   instruction. Pass actual admission before invoking the suite.

The prior independent reviewers supplied scoped findings, not personal
